# Bundled runtime dependencies

The runnable JAR includes Jackson Databind/Core/Annotations 2.18.2, sqlite-jdbc 3.47.1.0,
SLF4J API/NOP 2.0.16. License/notice files extracted from the original dependency JARs
are retained here. JUnit is test-only and not bundled in the runtime JAR.

Sources: https://github.com/FasterXML/jackson-databind , https://github.com/xerial/sqlite-jdbc ,
https://github.com/qos-ch/slf4j . No new license is assigned to the user's source repository.
